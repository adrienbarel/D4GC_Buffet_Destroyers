# Product: MSF Field Knowledge Hub (hackathon demo)

- Event: Data 4 Good Challenge 2026, pitch at 18:30 today, 5 minutes. Time is very short: always build the smallest thing that works, then improve.
- Users: MSF doctors and staff in missions with poor/no internet, limited storage and compute.
- Jury criteria: effectiveness (relevant docs, few false positives), creativity, implementability (on-premises, no single vendor), cost-effectiveness, presentation.
- We build the HUB side: index + text of all docs + originals chosen by a cost model, device sync per staff group, upstream fetch from a cloud server, simulated LoRa relay.
- The full, authoritative design is docs/PROJECT_SPEC.md. When something is unclear, read the relevant section there instead of guessing.
